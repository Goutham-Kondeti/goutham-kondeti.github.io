# Configurable Line-Listing Splitter

Portfolio-safe VBA demonstration using synthetic fields.

## Features
- User selects the source range instead of editing the code.
- User selects the patient-identifier header instead of hard-coding a column.
- Handles multiple rows for the same patient.
- Creates either separate Excel workbooks or multiple worksheets in one workbook.
- Sanitizes file and worksheet names.
- Includes cancellation and error handling.

## Run
1. Open Excel and save the workbook as `.xlsm`.
2. Press `Alt + F11`.
3. Import `Configurable_Line_Listing_Splitter.bas`.
4. Run `SplitLineListingInteractive`.
5. Select the source data range and patient-identifier header when prompted.

No PHI, employer data, client mappings, or proprietary code is included.
