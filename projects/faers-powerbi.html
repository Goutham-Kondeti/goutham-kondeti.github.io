The question

A Power BI portfolio project built from public FDA FAERS data, connecting report trends, country views and drug–reaction exploration.

01 /

Model and navigation

Started from downloaded FAERS ASCII files. Power Query work included data-type correction and profiling; a drug lookup relationship supports the model. DAX, drillthrough, Top N views, tooltips and Deneb visuals connect preparation and modeling to report exploration.

02 /

The artifact

The dashboard below is an existing project artifact showing an aggregate snapshot of public FAERS report data.

03 /

Interpretation matters

Spontaneous reports can be incomplete, duplicated or affected by reporting behavior. Report counts do not establish incidence or causality. The dashboard supports exploration and follow-up questions, not clinical or regulatory decisions.
