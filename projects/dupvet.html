Personal software / DupVet

DupVetKnow what matches.
Choose what happens.

A Windows application for exact duplicate-file and folder-tree review. SHA-256 evidence, comparison previews and recoverable quarantine separate finding a match from deciding what to do with it.

Explore the product ↓

01 / Establish the evidence

Compare more than a filename.

Choose reference and target locations, then inspect exact file and complete-folder matches. Read-only scanning uses SHA-256 evidence; cleanup is a separate, explicit action.

02 / Inspect the context

Open both sides of the decision.

A detached side-by-side preview keeps the two files visible together. Metadata, paths and copyable hashes support review before selecting an action. Rich document previews depend on the available Windows handlers.

03 / Keep assistance optional

Interpretation beside deterministic checks.

Buddi can use local Ollama or optional Gemini to explain scan results. A proposed cleanup still goes through confirmation and deterministic re-verification. Quarantine has a persistent restore ledger; scan history and undo/redo are session-local.

The build

Make the workflow understandable.

Built with C#/.NET 10 and WPF for Windows. The design separates scanning, evidence review, optional assistance and recoverable actions. Version 0.9.0 is a public beta.
