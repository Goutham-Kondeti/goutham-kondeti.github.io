MedSafe SafetyDB

Oracle SQL / ERD / normalization

The question

Model the workflow before the tables.

MedSafe SafetyDB is a Governors State University academic design for a fictional pharmacovigilance office.

← Back to all work
01 /

Translate requirements into relationships

Model cases, reporters, patients, products, events and submissions. Use cardinality and bridge tables to preserve many-to-many relationships and the context of a safety case.

02 /

Make integrity explicit

Normalization, primary and foreign keys, controlled values and Oracle SQL constraints express what a valid record should look like. Roles and security-point relationships model access concepts.

03 /

Evidence and scope

Conceptual and logical ERDs document an academic relational design for a fictional pharmacovigilance office.
