# Goutham Kondeti — Professional Portfolio

A responsive, accessible, privacy-conscious portfolio for healthcare informatics, pharmacovigilance systems, clinical data, analytics and applied AI.

## Included pages
- Home and professional positioning
- Filterable project portfolio
- Detailed professional experience
- Resume library with seven tailored downloadable resume versions
- Seven detailed case studies
  - OfficeMate-to-Barti EHR migration
  - FAERS post-market safety Power BI dashboard
  - Global pharmacovigilance systems reliability and automation
  - Configurable Excel VBA line-listing splitter
  - NLP-based ICSR information extraction
  - MedSafe pharmacovigilance database design
  - Healthcare, SAS-based RWE and predictive analytics

## Interactive features
- Light/dark theme with saved preference
- Responsive mobile navigation
- Project filtering
- Accessible tabs and keyboard navigation
- Animated impact metrics with reduced-motion support
- Active case-study table of contents
- Copy-email interaction and print-ready resume

## Technical approach
- Semantic HTML5
- Modern CSS with custom properties and responsive layouts
- Dependency-free JavaScript
- WCAG-conscious focus states, landmarks, skip link, keyboard controls and reduced motion
- SEO metadata and Schema.org Person JSON-LD
- GitHub Pages compatible; no build step required

## Experience content strategy
The website uses curated, role-relevant highlights from private master-experience documents. The complete master documents are intentionally not published.

## Privacy
Employer case studies are sanitized and use generalized descriptions or synthetic examples. No PHI, confidential client information, production data, proprietary screenshots, credentials or employer-owned code are included. See `PRIVACY_AND_CONFIDENTIALITY.md`.

## Run locally
```powershell
python -m http.server 8000
```
Then open `http://localhost:8000`.
